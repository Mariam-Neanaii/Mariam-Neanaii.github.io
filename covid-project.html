Project Overview

This project explores COVID-19 data using CDC and US Census Bureau datasets to identify patterns in mortality, demographics, and geographic regions.

The goal was to transform raw public data into meaningful insights using exploratory data analysis, statistical inference, regression, and data visualization.

Key Questions

  • How did COVID-19 mortality vary across different demographic groups?
  • Were there significant differences in mortality between regions?
  • Which factors appeared to be associated with higher death rates?
  • Can regression models help predict COVID-19 death rates?

Analysis Process

1. Data Collection

Used publicly available COVID-19 datasets from the CDC and demographic information from the US Census Bureau.

2. Data Cleaning & Preparation

Prepared the datasets for analysis by checking data quality, handling missing values, and organizing relevant variables.

3. Exploratory Data Analysis

Explored trends across time, demographic groups, and regions to identify meaningful patterns in COVID-19 mortality.

4. Statistical Analysis

Applied hypothesis testing to evaluate claims related to mortality and demographic differences.

5. Predictive Modeling

Developed regression models to investigate relationships between relevant variables and predict COVID-19 death rates.

6. Data Visualization & Storytelling

Created visualizations and supporting commentary to communicate findings clearly and transform analysis into actionable insights.
